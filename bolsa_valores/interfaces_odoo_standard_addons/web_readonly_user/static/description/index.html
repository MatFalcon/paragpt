Read Only User View.

This module enables the feature to set readonly view userwise.

List of Features


  • It Work With Both Community And Enterprise Version.
  • Easy to use, Administrator can set Readonly user without any technical knowledge.
  • User Wise Setting.
  • Set/Unset Any User To Read Only.
  • Readonly User can not create, Edit, Delete and Duplicate the Documents.

How it works

Click on Set Readonly button to set selected user to Read Only.


Before set user to Read Only, user can able to Create/Edit/Delete/Duplicate record.


Click on Unset Readonly button to reset read only behaviour.


After set user to Read Only, user Create/Edit/Delete/Duplicate options are not visible. If user click on any button System will raise access denied warning.


If user click on button that create any record or prcess some transaction then System will raise an Assess Error.
