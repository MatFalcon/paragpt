Account Analytic Plan Module
====================
Version: 1.0
Compatibility: Odoo 17

Este módulo facilita la gestión y seguimiento de firmas digitales dentro de Odoo.




Funcionalidades
====================
- Creación y gestión de firmas digitales directamente desde Odoo.
- Almacenamiento seguro de las firmas digitales en la base de datos, organizadas por empresa.
- Uso de un apodo (nickname) en caso de que no se disponga de una imagen de la firma digital.

Integración con el Chatter para registrar mensajes y actividades.
====================


Dependencias
====================
Este módulo depende de los siguientes módulos:

- purchase
- stock
- account
- account_cobros_py
- base
